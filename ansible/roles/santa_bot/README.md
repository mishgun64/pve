# santa_bot

Deploys the Telegram bot [Santa_Bobot](https://github.com/mishgun64/Santa_Bobot)
inside a Docker container on LXC 148 (`santa-bot`, `192.168.2.11`).

## Roles

| Role | Purpose |
|---|---|
| `santa_bot/config` | Clone the repo, deploy `data/secrets.json`, build & start the container |
| `santa_bot/backup` | Archive `data/` to the control node (`/srv/backups/santa_bot`) |
| `santa_bot/restore` | Restore the latest archive from the control node |

`config/tasks/secrets.yml` is shared by `config` and `restore`, because
`data/secrets.json` is deliberately excluded from backups.

## Bot token

The token is a secret and is never stored in the repository. Two options:

1. Encrypted file (recommended):

   ```bash
   cp ansible/roles/santa_bot/config/files/secrets-example.yml \
      ansible/roles/santa_bot/config/files/secrets.yml
   # edit santa_bot_token, then encrypt
   sops --config ansible/roles/santa_bot/config/files/.sops.yaml \
        -e ansible/roles/santa_bot/config/files/secrets.yml \
        > ansible/roles/santa_bot/config/files/secrets.enc.yml
   rm ansible/roles/santa_bot/config/files/secrets.yml
   ```

2. Extra variable at runtime:

   ```bash
   ansible-playbook -i ansible/hosts_prod ansible/run_role.yml \
     -e role_name=santa_bot/config -e target_hosts=santa_bot_lxc \
     -e santa_bot_token=...
   ```

## Docker image

The upstream `dockerfile` installs `pyTelegramBotAPI` into `/app/pip` without
adding it to `PYTHONPATH`, so the bot cannot `import telebot`. The role ships
`files/Dockerfile`, copied to the LXC as `Dockerfile.ci` and used by
`docker compose build`. It also symlinks `/data` -> `/app/data`, because
`main.py` writes its database to the absolute path `/data/db.json`, while the
volume is mounted to `/app/data`.

`docker-compose.yml` pins `image: santa_bot:latest` and `pull_policy: never`,
so the daily `docker compose pull && docker compose up -d` cron from
`common/docker` does not try to fetch a non-registry image and does not fail
the whole stack. The role always rebuilds explicitly with
`docker compose up -d --build`.

## Data

`data/users.json` comes from the repository, `data/secrets.json` is generated by
the role. The container runs as uid/gid 1000 (`docker`), matching the owner of
`/home/docker/santa_bot`.

## Playbook

```bash
ansible-playbook -i ansible/hosts_prod ansible/santa_bot.yml
```
